# 平台选择

得益于 Java 的跨平台，我们可以在不同的操作系统 (OS) 来运行 Minecraft 服务器。

常见的 OS 有 Windows, MacOS, Linux 和其不同的发行版。下面我们将对每个系统在 Minecraft 开服方面的表现进行一定分析。

## Windows

个人感觉 Windows 并不适合长期运行 Minecraft 服务器。

## MacOS / Linux

我们使用 Mac Mini (MacOS) 和 Linux (NixOS, Debain) 服务器进行开服。
