# 平台选择

得益于 Java 的跨平台特性，我们可以在不同的操作系统（OS）上运行 Minecraft 服务器。

一般来说，只要设备能够安装合适版本的 Java，就可以运行 Minecraft 服务端。不过，不同平台在使用体验、稳定性和维护方式上会有一些区别。

## Windows

Windows 是最容易上手的平台之一。它有完整的图形界面，文件管理和服务端配置都比较直观，适合新手学习开服，也适合在本地测试插件、Mod 或数据包。

### 笔记本

使用 Windows 笔记本开 Minecraft 服务器很方便，启动服务端、修改配置和查看日志都比较简单。

不过，常用笔记本并不适合长期运行服务器。合盖休眠、系统更新、无线网络波动、散热限制等问题，都可能导致服务器中断或卡顿。因此，它更适合作为临时测试环境，而不是正式服务器。

### 台式机 / 服务器

相比笔记本，台式机和服务器更适合长期运行 Minecraft 服务端。它们通常有更稳定的供电、更好的散热和更可靠的网络连接，持续运行时也更不容易受到日常使用的影响。

如果你希望在 Windows 上长期运行服务器，建议优先选择闲置台式机或专门的 Windows 服务器，而不是自己的日常笔记本。

## macOS

macOS 同样可以运行 Minecraft 服务端。它既有图形界面，也有接近 Linux 的终端环境，适合本地测试、开发和轻量开服。

### Mac Mini

Mac mini 体积小、功耗低、噪音小，很适合作为个人小服务器。它可以用来长期运行生存服，也可以顺便运行一些其他轻量服务。

如果你手头刚好有一台闲置的 Mac mini，用它开 Minecraft 服务器是一个不错的选择。

## Linux

Linux 是长期运行 Minecraft 服务器时最常见的平台。它资源占用低，远程管理方便，也更适合自动重启、自动备份和日志管理。

常见的 Linux 发行版包括 Debian、Ubuntu 和 NixOS。其中 Debian 和 Ubuntu 更适合大多数用户入门，NixOS 则更适合喜欢声明式配置和可复现部署的用户。

文章后续教程将以 Debain 为例，但文章中重要的命令 / 脚本将提供 Windows 版本。
