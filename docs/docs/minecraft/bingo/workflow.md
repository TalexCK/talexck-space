# Bingo 运行流程

本文档记录一次 Bingo 活动从开服到赛后处理的流程。

## 开赛前

1. 启动服务端。
2. 确认日志无严重报错。
3. 玩家进入服务器。
4. 裁判确认语音、权限和人数。
5. 确认 Bingo 配置和游戏模式。

## 游戏中

游戏中主要关注：

- TPS 是否稳定。
- 玩家是否大量掉线。
- Bingo 面板 / 统计是否正常。
- 裁判是否能旁观。
- 语音是否正常。

如果出现大范围卡顿，不要立即重启。先确认是否是区块生成峰值，必要时暂停开局节奏。

## 游戏结束

1. 确认成绩。
2. 保存日志。
3. 如有统计文件，单独备份。
4. 停服。
5. 处理世界目录，为下一局做准备。

## 重开一局

重开前确认：

- 上一局日志已经保存。
- 世界目录已经按需要重置。
- 玩家列表清理完毕。
- MOTD 状态正确。

## 异常中止

如果活动必须中止：

1. 通知玩家停止操作。
2. 保存当前日志。
3. 执行 `stop`。
4. 复制服务端目录作为现场。
5. 再决定是否重开。
