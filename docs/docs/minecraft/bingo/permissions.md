# Bingo 权限

Bingo 权限比生存服简单，但活动现场更容易出问题。建议提前配置好玩家、裁判和维护人员
三类角色。

## 玩家组

普通玩家只需要：

- 进入服务器。
- 使用 Bingo 玩法基础命令。
- 使用语音。
- 查看必要信息。

普通玩家不应拥有 Vanish、管理命令或强制结束游戏的权限。

## 裁判组

裁判可以拥有：

- 旁观相关权限。
- Vanish 权限。
- 查询玩家状态。
- 处理比赛争议所需的只读命令。

裁判不一定需要 OP。

## 管理员组

管理员可以拥有：

- LuckPerms 管理。
- 游戏开始 / 停止控制。
- 玩家传送。
- 服务端控制台权限。
- 日志与文件访问权限。

管理员权限应控制人数，活动时越多人拥有管理权限，误操作概率越高。

## 白名单

当前 `white-list=false`。如果活动是邀请制，建议开服前启用白名单，而不是等开赛后
再手动踢无关玩家。

## 排查权限问题

如果玩家无法执行 Bingo 命令：

1. 确认 LuckPerms 是否加载。
2. 确认玩家所在组。
3. 确认 Fabric permissions 是否正常。
4. 查看 Bingo Mod 是否有自己的权限节点。
