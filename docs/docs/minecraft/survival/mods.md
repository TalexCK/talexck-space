# 生存服 Mod

生存服使用 Fabric Mod 生态。下述记录 Mod 列表：

## 基础依赖

- [Fabric API](https://modrinth.com/mod/fabric-api)：Fabric 生态基础 API。
- [Cloth Config](https://modrinth.com/mod/cloth-config)：部分 Mod 的配置前置。
- [YetAnotherConfigLib](https://modrinth.com/mod/yacl)：部分 Mod 的配置前置。

## 权限与管理

- [LuckPerms](https://luckperms.net/)：权限组、玩家权限和继承关系。
- [vanilla-permissions](https://modrinth.com/mod/vanilla-permissions)：把原版命令权限接入 Fabric 权限系统。
- [spark](https://spark.lucko.me/)：性能采样和 TPS / MSPT 分析。
- [Servux](https://modrinth.com/mod/servux)：给客户端辅助工具提供服务端数据。

## 生电

- [Carpet](https://github.com/gnembon/fabric-carpet)
- [Carpet TIS Addition](https://modrinth.com/mod/carpet-tis-addition)
- [Gugle Carpet Addition](https://modrinth.com/mod/gugle-carpet-addition)
- `sandstone_fast_rails`：铁轨加速 Mod，游戏内修改。

## 玩家功能

- [Blossom TPA](https://modrinth.com/mod/blossom-tpa)：玩家传送请求。
- [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat)：语音聊天。
- [JEI](https://modrinth.com/mod/jei)：物品和合成查询。

## 性能优化

- [C2ME](https://modrinth.com/mod/c2me-fabric)：区块加载和世界生成优化。
- [FerriteCore](https://modrinth.com/mod/ferrite-core)：降低内存占用。
- [Krypton](https://modrinth.com/mod/krypton)：网络优化。
- [Packet Fixer](https://modrinth.com/mod/packet-fixer)：网络包修复。
- [ScalableLux](https://modrinth.com/mod/scalablelux)：光照优化。

## 世界生成

- [Moog's End Structures](https://modrinth.com/mod/moogs-end-structures)
- [Moog's Missing Villages](https://modrinth.com/mod/moogs-missing-villages)
- [Moog's Nether Structures](https://modrinth.com/mod/moogs-nether-structures)
- [Moog's Soaring Structures](https://modrinth.com/mod/moogs-soaring-structures)
- [Moog's Temples Reimagined](https://modrinth.com/mod/moogs-temples-reimagined)
- [Moog's Voyager Structures](https://modrinth.com/mod/moogs-voyager-structures)

## 安全与保护

- [seedguard](https://modrinth.com/mod/seedguard)：保护世界种子。
- [antixray](https://modrinth.com/mod/anti-xray)：反矿透相关配置。
