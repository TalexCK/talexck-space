# WorldGit 可视化菜单

玩家通过右键打开 Chest UI，在菜单里完成选区、创建分支、进入分支、提交审核、处理冲突和确认合并。

## 入口

玩家上线、切换世界、重生后，插件会自动检查快捷栏第 `9` 格，并放入一本 WorldGit 菜单书。

菜单书特性：

- 物品类型是书，显示名为“菜单书”
- 固定放在快捷栏第 `9` 格
- 右键打开玩家面板
- 玩家不能把菜单书丢出背包
- 如果第 `9` 格原本有物品，插件会先尝试把原物品移到背包，背包满时掉落在玩家附近

也可以直接输入：

```text
/wg  // 打开 WorldGit 玩家面板
```

如果菜单书丢失、显示异常，通常重新进服、切换世界、重生，或执行 `/wg` 都可以重新进入菜单。

## 玩家主面板

玩家主面板标题为“玩家面板”，是 WorldGit 最常用的入口。面板顶部是全局操作，中间按状态展示分支，底部放辅助入口。

顶部按钮：

- `设置 Pos1`：左键把当前坐标设为 Pos1，右键打开告示牌手动输入坐标
- `设置 Pos2`：左键把当前坐标设为 Pos2，右键打开告示牌手动输入坐标
- `当前选区`：只读展示当前世界、Pos1、Pos2 和已选点位数量
- `创建分支`：选区满足条件时进入创建确认页
- `确认合并`：存在已审核通过的分支时，进入合并分支选择页
- `返回主世界`：从分支世界传送回主世界
- `管理员留言`：展示最近的审核意见或管理员备注
- `当前审核分支`：审核员正在看某个分支时，可快速回到该分支审核面板
- `刷新菜单`：重新读取分支、选区、队列和权限状态

主面板中部会分两块展示分支：

- `正在修改的分支`：显示状态为 `ACTIVE` 或 `REJECTED` 的可编辑分支
- `等待中的分支`：显示已提交审核、已通过待确认合并，以及玩家当前排队选区

主面板底部入口：

- `玩家帮助`：在菜单内提示 Pos1 / Pos2、告示牌输入、Rebase、合并等基本操作
- `合并记录`：打开已合并分支的分页记录
- `查看全部分支`：打开全服分支总览，允许预览未合并分支
- `审核入口`：拥有 `worldgit.admin.review` 权限时显示

## 选区与创建分支

创建分支前需要先设置 Pos1 和 Pos2。菜单支持两种方式：

- 左键 `设置 Pos1` / `设置 Pos2`：使用玩家当前脚下坐标
- 右键 `设置 Pos1` / `设置 Pos2`：打开临时告示牌输入坐标

告示牌坐标支持：

```text
整数    // 例如 -1917、73、2048
~       // 使用打开告示牌时的当前轴坐标
~+5     // 在当前轴坐标基础上加 5
~-3     // 在当前轴坐标基础上减 3
```

可以按两种格式填写：

- 第 `2 / 3 / 4` 行分别输入 `X / Y / Z`
- 或直接从第 `1 / 2 / 3` 行输入 `X / Y / Z`

点击 `创建分支` 后会进入创建确认界面。这个界面会展示：

- 本次选区范围
- 总方块数量
- 与已有未合并编辑区的重叠方块数
- 重叠率
- 重叠区域列表
- 分支标签输入入口

如果没有重叠，确认后会直接创建分支并传送到分支世界。如果检测到重叠，界面会变成“创建分支重叠确认”，玩家需要明确确认自己接受重叠风险。

## 分支详情

点击主面板中的分支卡片，会进入“分支详情”界面。这里是单个分支的操作中心。

分支详情会展示：

- `基线信息`：base revision、sync 状态、未解决冲突组数量
- `主线状态`：当前主线 head、待吸收 commit、额外同步提示
- `状态总览`：分支标签、分支状态、世界名、编辑区域坐标
- `协作者`：当前分支建造者列表
- `审核记录`：审核人、审核时间、审核基线
- `分支标签`：创建者可通过告示牌修改标签

可执行操作：

- `进入分支`：传送到该分支世界
- `执行 Rebase`：把分支重放到最新主线，并触发冲突检测
- `冲突中心`：打开该分支的冲突组列表
- `提交审核`：将 `ACTIVE` 或 `REJECTED` 分支提交给管理员审核
- `确认合并`：对 `APPROVED` 分支进入最终确认
- `切回编辑`：把已通过审核的分支切回可编辑状态
- `执行 Fetch`：拉取主线最新状态，不直接替换分支方块
- `放弃分支`：进入放弃确认页
- `返回玩家面板`：回到主菜单

这里的 `Fetch` 和 `Rebase` 要区分开：

- `Fetch` 只更新主线状态认知，不直接改动分支方块
- `Rebase` 会把分支同步到新的主线基础上，必要时生成冲突组

## 冲突中心

当 Rebase 发现分支编辑区和主线都有变化时，WorldGit 会生成冲突组。玩家可以从分支详情进入“冲突中心”。

冲突中心列表页会显示：

- 冲突总组数
- 未解决组数
- 当前页码
- 已选择冲突组数量
- 每个冲突组的范围、块数和状态

列表页操作：

- 左键冲突组：勾选或取消勾选
- 右键冲突组：进入单个冲突组详情
- `全选本页`：选择当前页所有未解决冲突
- `全选全部`：选择该分支全部未解决冲突
- `清空选择`：清空当前勾选
- `批量 mine`：对已选冲突组保留分支版本
- `批量 theirs`：对已选冲突组采用主线版本
- `批量完成`：把已选冲突组标记为手动处理完成

单个冲突组详情会展示：

- 组编号
- 冲突块数
- 冲突范围
- 当前解决状态
- `mine` 变化摘要
- `theirs` 变化摘要

单组处理操作：

- `接受 mine`：保留分支里的版本
- `接受 theirs`：采用主线里的版本
- `手动处理`：传送到冲突现场，并进入冲突木棍模式
- `标记已解决`：玩家手动改完后标记该组完成

冲突木棍模式下：

- 左键选择冲突区域
- 右键在 `mine` / `theirs` 之间切换
- 手动改块会被记录，之后可以回菜单标记完成

## 审核菜单

拥有 `worldgit.admin.review` 权限的玩家，会在主面板右下角看到 `审核入口`。

审核列表分为两个页签：

- `待审核`：玩家首次提交、还没有审核基线的分支
- `需复审`：主线更新后需要重新检查的分支

审核列表里点击分支，会进入审核操作面板。审核操作面板包含：

- `传送到分支`：进入被审核分支世界
- `改动摘要`：查看该分支相对基线的变化概况
- `同步摘要`：查看标签、sync 状态、base/head、上次审核基线
- `高亮改动方块`：打开或关闭改动方块高亮
- `批准分支`：通过审核，让玩家进入确认合并阶段
- `驳回分支`：打开告示牌输入驳回原因，并把分支退回给玩家修改
- `返回列表`：回到待审核列表
- `玩家菜单`：回到玩家主面板

## 合并确认与合并记录

分支通过审核后，玩家不会立刻把内容写回主世界。WorldGit 会要求玩家在菜单里做最后确认。

合并流程：

1. 管理员在审核菜单批准分支
2. 玩家主面板出现 `确认合并`
3. 玩家选择要合并的已批准分支
4. 进入最终确认页
5. 输入合并说明
6. 插件开始把分支内容合并回主世界

合并说明通过临时告示牌填写。第 `1` 到第 `4` 行都可以写，多行会自动合并成一条记录；如果留空，记录里会显示为未填写合并说明。

合并完成后，玩家可以在 `合并记录` 里查看：

- 建造者
- 批准者
- 合并者
- 合并说明
- Pos1 / Pos2
- 对应分支世界传送入口

## 全部分支总览

主面板底部的 `查看全部分支` 会打开全服分支总览。这个页面用于观察当前 WorldGit 中还存在的所有分支。

总览页会展示：

- 分支总数
- 未合并分支数量
- 分页列表
- 每个分支的所有者、标签、状态和区域信息

对未合并分支，玩家可以左键传送预览。非成员进入后只读不可修改。
